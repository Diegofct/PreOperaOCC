# Tareas — Spec 047, Requisición de pagos de OCC

Tareas de menos de 30 minutos, ordenadas por dependencia. Cada una lleva los RF que
cubre y una línea `Hecho cuando:` que se pueda comprobar sin interpretar.

**Se implementa una tarea cada vez** (`/sdd:implementar T1`), y al terminarla se para.
Ninguna tarea se marca sin `npm run verificar`, `npm run typecheck` y `npm run lint`
en verde. Por eso, «en verde» abajo significa esos tres comandos.

Producción no se toca: la migración va solo a `neondb`. Diego enciende su servidor en el puerto
8081 (no se enciende otro); tras tocar una ruta `+api.ts` hay que pedirle que lo reinicie, porque no
las recarga. Las pruebas nuevas de `scripts/verificar-reglas.ts` llevan el prefijo «047/». Lo de
prueba en vivo lleva `PRUEBA-047` y vive solo en desarrollo.
